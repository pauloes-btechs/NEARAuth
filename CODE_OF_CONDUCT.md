# Code of Conduct

## Our pledge

We want NEARAuth to be a welcoming project for everyone, regardless of background, identity or experience level.

## Expected behaviour

- Be respectful and constructive; critique ideas, not people.
- Assume good intent and ask before assuming.
- Accept feedback gracefully and give it kindly.
- Respect privacy: never share others' personal information.

## Unacceptable behaviour

Harassment, discriminatory language, personal attacks, sexualised content, doxxing, and sustained disruption of discussions.

## Enforcement

Report concerns privately to the repository owner (@pauloes-btechs) through GitHub. Maintainers may edit or remove contributions, and warn or ban participants, for behaviour that violates this code. Reports are handled confidentially.

This code applies in all project spaces (issues, pull requests, discussions) and when representing the project publicly. It is adapted from the spirit of the Contributor Covenant, v2.1.
