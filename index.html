EXPOSURE INTELLIGENCE

Know where your data goes

Each service gets a one-of-a-kind address. Unexpected use becomes an investigation, not an unsupported accusation.

Each click sends the next simulated inbound message (four scenarios) through the detection engine. An unexpected sender can indicate sharing, a vendor relationship, a breach, or forged sender information. It is not proof a company sold your email.
VERIFIABLE AUDIT TRAIL

Trust, with receipts.

Event commitments can eventually be anchored to NEAR for tamper-evident verification. Commitments are hashed locally and pinned to a live NEAR Testnet block read over public RPC. Writing commitments on-chain is not enabled yet.

BUILT BY BTECHS · OPEN SOURCE

Private by default. Open by design.

NEARAuth is a vision for masking identities everywhere you sign up, with proof when an alias starts appearing elsewhere.

◈
Browser first

The extension lives in the signup flow, not in a separate workflow. A real Manifest V3 prototype is included.

✉
Forwarding next

Production will need a routable owned email domain or an authorized third-party relay provider. GitHub Pages cannot receive email.

⬡
Verified accountability

NEAR will eventually anchor privacy-preserving audit commitments, not raw email addresses or passwords.

♧
Mobile compatible

Native Android and iOS autofill and credential-provider integrations are planned as companion releases.

⚑
Collaborative engineering

GitHub PRs, issues, CI, contributor guidelines, security review, and Pages deployment workflows.

▣
No fake security claims

Demo-mode activity is locally simulated and clearly separated from working email, password storage, and blockchain production services.
