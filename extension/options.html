NEARAuth options

Alias provider

Prototype notice: the token is kept in this browser's extension storage, unencrypted, and is sent only to https://app.addy.io. Use a token you can revoke. Chrome will ask you to allow access to app.addy.io when you save.

How this works

  • With Demo, nothing ever leaves your browser.
  • With addy.io, clicking “Generate Private Email” asks addy.io to create an alias described as “NEARAuth: <site>”. Mail to that alias is forwarded by addy.io to your default recipient.
  • If the provider call fails, NEARAuth falls back to a demo alias and tells you so in the form.
